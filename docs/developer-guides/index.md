its templates/assets).

- [Development Setup](./development-setup.md) — building, running, and testing locally

- [Testing](./testing.md) — how the test suite is structured and run
- [Pitfalls](./pitfalls.md) — non-obvious decisions and known gotchas
- [Contributing](./contributing.md) — branch naming, commits, and the review flow
